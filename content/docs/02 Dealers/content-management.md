# Content management

<!-- tags: dealer, content, connectors, gds, ndc, travelfusion, hotels -->

Every user with an **agency** role can turn content connectors on or off for a dealer. This is managed under **Dealers → Edit → Chosen connectors**.

## What you can do

- **Disable a connector** — uncheck it and click **Save**
- **Enable a connector again** — check it and click **Save**

The list shows the connectors that are currently set for that dealer. You only need to change the checkboxes and save — no other configuration is required here.

> **Important:** You can only switch connectors that are already set as default for your agency. Connectors that are not part of your default setup cannot be turned on here.

## Connector glossary

| Connector name | Content |
|----------------|---------|
| Air Ticket Galileo | GDS |
| Air Ticket Galileo uAPI | GDS |
| Travelfusion tickets | Travelfusion |
| Air Ticket TP JSON API | Travelport NDC |
| Hotels Go Global | Hotel content |

## How to change connectors

1. Log into the GOL IBE admin console.
2. Go to **Dealers**.
3. Open the dealer and click **Edit**.
4. Open **Chosen connectors**.
5. Uncheck a connector to turn it off, or check it to turn it on.
6. Click **Save**.

See also: [GDS Connectors](/portal/advanced-settings/connectors)
